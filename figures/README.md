# Figures for the manuscript

High-resolution (600 dpi) PNG files of all figures built in `trends_hb_nitro.ipynb`.
File names match the figure numbers in the manuscript (e.g. `Figure 12.png`, `Figure 21a.png`).
The files are (re)created by `pf.save_fig(...)` calls in the notebook cells - run the notebook from the top.

Note: Figure 6 is the base plot; the annotations shown in the manuscript are added on top of it.
